# Test scenarios

Start with `start.bat`. For each test, speak or type the command, then write Pass or Fail.

| # | You say | Expected result | Result |
|---|---------|-----------------|--------|
| 1 | What is the capital of Australia | Answers Canberra, by voice and text | |
| 2 | Explain AI in simple words | Short, plain answer | |
| 3 | भारत की राजधानी क्या है | Answers in Hindi | |
| 4 | What is today's date | Gives the correct date | |
| 5 | Open Notepad | Notepad opens | |
| 6 | Open camera | Windows Camera app opens | |
| 7 | Open YouTube | YouTube opens in the browser | |
| 8 | Search weather in Delhi | Google search opens | |
| 9 | Play lo-fi music | YouTube search opens | |
| 10 | Volume up / Volume down / Mute | Volume changes | |
| 11 | Lock the laptop | Asks Allow or Deny. Allow locks it. Deny cancels | |
| 12 | Shut down | Asks Allow or Deny. Deny cancels. (If allowed, run `shutdown /a` to stop it) | |
| 13 | Language button, then speak Hindi | Hindi is understood | |
| 14 | Use Brave browser, tap the core | Switches to server listening and still works | |
| 15 | Close the server window, then ask anything | Says the server is offline | |
| 16 | Start without a key | Says no API key was found | |
| 17 | Turn off the internet, then ask a question | Says it could not reach the AI service | |
